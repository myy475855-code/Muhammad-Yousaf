## Run
Because the portfolio loads JSON with `fetch()`, use a local server rather than opening `index.html` directly.

### VS Code
1. Open the `modern_portfolio` folder.
2. Install/use Live Server.
3. Right-click `index.html` → Open with Live Server.

Or use Python:
`python -m http.server 8000`
Then open `http://localhost:8000`.

## Personalize

- `data/projects.json`
- `data/experience.json`
